# Interview Code Test Instructions

The goal is to connecting an existing API endpoint to a react component and follow application standards and patterns

The API Documentation is here: https://dogapi.dog/docs/api-v2.

For submissions, either clone this repo and make your own, or create a separate branch with your name and push.

- Use the /breeds endpoint.
- A component "Dogs.tsx" has already been created for you. Follow the same patterns used in the UserCard.tsx, and in queries/User.tsx to have the component render the dog breeds.
- Implement the component to render information about the first 5 dog breeds returned from the API
- Styling does not matter
- This API does not require any authentication to make it easier
